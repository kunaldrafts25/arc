## Latest research: read and extend it

Read docs/deep_research_2026_10_29.md and docs/learning_gap_review.md first.
They connect our failures to 13 primary sources, with assumptions and limitations:

1. EMPA/theory-based RL: causal object interactions, conditional rules and joint
   goal learning. Its experiments assume some object identities and restrict
   goal types; this is not proof of arbitrary black-box ARC understanding.
2. WorldCoder: executable model synthesis and optimistic exploration. Assumes
   symbolic states, deterministic dynamics and a supplied natural-language goal.
3. Executable World Models for ARC3: checked programs and compact abstractions;
   frontier-model public results do not establish private/offline transfer.
4. Tycho: active abstraction and partial prediction. Actor-requested modeling
   outperformed automatic repair in one matched public comparison even though
   repair improved transition match. Model correctness is not action usefulness.
5. CEGIS: use concrete counterexamples to refine proposals, while recognizing
   finite environment observations are not an exhaustive formal verifier.
6. Bayes-adaptive POMDPs: uncertainty over hidden state and dynamics matters.
   Do not invent calibrated probabilities from model confidence language.
7. POMCP: search with beliefs needs a usable generative model; MCTS alone does
   not discover missing mechanics, relevant state or objectives.
8. DreamCoder: compositional program/library learning. Explore reusable measured
   operations and solver fragments rather than a universal static rulebook.
9. Options: reusable skills require initiation conditions, closed-loop behavior
   and stopping/interrupt conditions; fixed action macros are fragile.
10. Rational metareasoning: allocate thinking, model repair, search and acting
    by expected decision value, using practical bounded approximations.
11. DreamerV3: trained latent models support imagined rollouts, but starting a
    full RL training project is not justified by our current data/time/resources.
12. DAgger: if distilling, include learner-induced failure and recovery states;
    clean expert wins alone miss sequential distribution shift.
13. STaR: verified outcome filtering can guide training; a correct outcome does
    not certify its rationale or establish interactive generalization.

## New prototype, actual results and missing integration

hydra/prediction_ledger.py is a standalone finite deterministic hypothesis tool:
- Freezes forecasts before outcome; tickets are single-use and step-checked.
- Compares measured JSON features, distinguishing missing observation and
  abstention from a successful prediction.
- Keeps per-candidate counterexamples through bounded evidence eviction.
- Enforces level/step scope; requests new hypotheses if all candidates fail.
- Ranks coverage-weighted predicted-outcome disagreement per declared cost.
  This is a heuristic, not a calibrated posterior or optimal task-value policy.
- Does not execute actions or change the deployed sandbox/notebook.

scripts/benchmark_prediction_ledger.py ran 768 synthetic episodes, 128 matched
seeds for each policy/family combination. With eight supplied candidates:
- Direct identification: random 6.96 actions average; informed selection 3.
- Setup-dependent identification: random 11.89; supplied two-action lookahead 4.
- Greedy immediate information selection stopped and failed all 128 setup cases.
  A production agent needs fallback exploration, not a stop when information
  score is zero. Lookahead executed one action and replanned after observing.

Critical limitation: candidate programs INCLUDED the correct rule, exact features
were supplied, and the prerequisite was already in the model class. This does
not test pixel perception, LLM hypothesis generation, goal discovery, held-out
mechanics or actual ARC scoring. Ten new semantic tests plus 23 existing planner/
memory tests passed together, 33 total. No gameplay improvement is established.
No ARC3 weights were trained. The prototype is not integrated with the real host,
durable tool state or automatic model feedback yet.
